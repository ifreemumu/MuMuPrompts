# MuMu Prompts

이미지 생성 프롬프트와 글쓰기 템플릿을 모아 두고, 필요한 부분만 바꿔 다시 쓰는 개인용 보관함입니다.

**바로 열기 → https://ifreemumu.github.io/MuMuPrompts/**

## 쓰는 법

1. 카드를 눌러 프롬프트를 엽니다.
2. `내 상황에 맞게 바꾸기`의 입력칸을 채우면 최종 프롬프트에 바로 반영됩니다.
3. `최종 프롬프트 복사하기`를 눌러 원하는 AI 도구에 붙여 넣습니다.

## 구성

- `index.html` — 앱 전체 (프롬프트 데이터 포함, 외부 의존성 없음)
- `assets/` — 예제 이미지

브라우저 안에서만 동작하며, 입력한 내용은 서버로 전송되지 않습니다.
