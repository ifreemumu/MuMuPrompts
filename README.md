# MuMu Prompts

이미지 생성 프롬프트와 글쓰기 템플릿을 모아 두고, 필요한 부분만 바꿔 다시 쓰는 개인용 보관함입니다.

## 개인용으로 실행하기

GitHub에 앱을 공개하지 않고도 사용할 수 있습니다. 이 폴더 전체를 컴퓨터에 두거나 Google Drive 동기화 폴더에 복사한 뒤, 아래 명령으로 로컬에서 실행하세요.

```powershell
.\start-local.ps1
```

브라우저에서 `http://localhost:8080`을 엽니다. `index.html`을 더블클릭하거나 Google Drive 웹 미리보기에서 직접 열지 말고, 반드시 로컬 서버를 통해 실행해야 Google 로그인과 Drive 백업이 정상적으로 동작합니다.

## Google OAuth 최초 설정

Google Cloud Console의 Google Auth Platform → 클라이언트에서 현재 웹 OAuth 클라이언트의 승인된 JavaScript 원본에 아래 주소를 추가하세요.

```text
http://localhost:8080
```

`127.0.0.1:8080`으로 접속할 경우에는 `http://127.0.0.1:8080`도 별도로 등록해야 합니다. 관리자 계정은 OAuth 동의 화면의 테스트 사용자에도 등록되어 있어야 합니다.

## 사용과 백업

1. 카드를 눌러 프롬프트를 엽니다.
2. `내 상황에 맞게 바꾸기`의 입력칸을 채웁니다.
3. `최종 프롬프트 복사하기`를 눌러 원하는 AI 도구에 붙여 넣습니다.
4. 관리자로 로그인하면 프롬프트를 추가·수정할 수 있습니다.
5. 자료를 Google Drive에 보관하려면 `백업 → 드라이브에 백업하기`를 누릅니다.
6. 다른 컴퓨터에서는 같은 앱 폴더를 실행한 뒤 `백업` 메뉴에서 Drive 백업을 복원합니다.

앱 자료는 현재 브라우저의 IndexedDB/localStorage에 저장됩니다. 다시 열어도 로컬 자료를 우선하며, 삭제한 기본 자료를 자동으로 추가하지 않습니다. 게시 자료가 다르면 `백업 → 게시 자료 확인·가져오기`에서 비교 후 교체할 수 있습니다. 교체 전 자료는 `교체 전 자료 복구`로 되돌릴 수 있습니다(최근 1회).

관리자가 자료를 추가·수정·삭제하거나 복원하면 약 1.2초 뒤 Drive의 공개 게시 파일에 자동 반영합니다. 이미지 업로드도 Drive에 공개 읽기 권한으로 저장됩니다. 공개하면 안 되는 자료는 온라인 관리자 모드에 입력하지 마세요. 복사 횟수 변경은 게시하지 않습니다. 서로 다른 게시 자료를 발견하면 자동 게시를 중단하며, 백업 메뉴에서 가져오거나 명시적으로 로컬 자료를 게시할 수 있습니다.

JSON 백업과 HTML 저장은 이미지 원본을 포함합니다. 이미지 다운로드가 실패하면 오류를 표시하고 백업 생성을 중단합니다. HTML 저장은 앱 코드와 스타일도 포함하며, Google 연결이 없는 오프라인 편집용 사본으로 실행됩니다. 로컬 글꼴 대신 시스템 글꼴을 사용합니다. 브라우저가 파일 저장소를 허용하지 않으면 변경 후 JSON/HTML을 다시 저장하세요.

## 구성

- `index.html` — 화면 구조
- `js/core.js` — 프롬프트 검증·검색·입력값 처리
- `js/app.js` — 화면 이벤트·저장·Google 연동·백업
- `data/seeds.js` — 최초 실행용 기본 프롬프트
- `styles/app.css`, `tokens.css` — 화면 스타일
- `privacy.html` — 개인정보처리방침
- `assets/` — 앱에 포함된 이미지
- `fonts/` — 로컬 글꼴 파일
- `start-local.ps1` — 개인용 로컬 서버 실행 스크립트

첫 실행과 게시 자료 확인 시 공개 자료를 Google API에서 읽습니다. 관리자 편집 시 자동 게시하며, Drive 백업 버튼은 별도의 백업 파일을 만듭니다. 배포할 때는 index.html과 함께 js/, data/, styles/, assets/, fonts/, tokens.css를 모두 포함하세요.
